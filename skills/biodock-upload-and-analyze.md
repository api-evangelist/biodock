# Upload images and run a Biodock analysis

Biodock's public API is a REST API at `https://app.biodock.ai/api/external`.
Authenticate every request with the `X-API-KEY` header (generate a key in the
app under Settings -> API). Pipelines and AI models must be created in the app
UI first; the API can only run already-published, user-created pipelines.

## Steps

1. **Verify the key** — `checkApiKey` (`GET /check`). Confirms the key is valid
   and returns the user id and email before you do real work.
2. **Pick a pipeline** — `listPipelines` (`GET /pipelines`). Choose the `id` of
   a published pipeline to run. Only user-created pipelines are supported, not
   Biodock-authored ones.
3. **Upload each file** — `uploadFile` (`POST /filesystem-items/upload-file`,
   `multipart/form-data`) with `fileName`, optional `destinationFolder` (created
   if missing), and the `upload` binary. Files up to 2 GB; supported formats
   include png, jpg/jpeg, tif/tiff, svs, ndpi, vms, vmu, scn, svslide, bif.
   Keep each returned `id`.
4. **Submit the job** — `submitAnalysisJob` (`POST /analysis-jobs`) with
   `pipelineId` and `filesystemIds` (the uploaded file ids, or a folder id) and
   an optional `name`. Returns a job with `status: PENDING`.
5. **Poll to completion** — `fetchAnalysisJob` (`GET /analysis-jobs/{id}`) until
   `status` is `SUCCEEDED`. Read `objectsDataCSVUrl` and `aggregateDataCSVUrl`
   for the results.
6. **(Optional) Get segmentation masks** — masks are not generated by default.
   Call `submitDownloadMasksJob` (`POST /analysis-jobs/{id}/download-masks`),
   then poll `fetchDownloadMasksJob` (`GET /analysis-jobs/{id}/download-masks`)
   until `SUCCEEDED` and download `masksZipUrl`.

## Rules

- Auth: `X-API-KEY` header on every call. The key grants access to your data;
  keep it secret.
- Async: analysis and mask jobs are submit-then-poll; do not assume synchronous
  results. Statuses: PENDING, SUBMITTED, RUNNING, SUCCEEDED, FAILED.
- No idempotency contract is documented — do not blindly retry a submit; a
  duplicate submit creates a second job.
- Pagination on list endpoints uses `limit` + `startingAfter` (cursor); read
  `results` and `count`.
- The API is in beta; resources may change.
